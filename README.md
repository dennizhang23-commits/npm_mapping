# npm-map-routing

## Getting Started

To run the project locally:

```bash
npx http-server -o /docs-site/
```

This will start the server from the project root and automatically open the documentation site in your browser.

Alternatively, you can start the server without auto-opening:

```bash
npx http-server
```

Then manually navigate to:
- Documentation: `http://localhost:8080/docs-site/`
- Route Creator: `http://localhost:8080/routeCreator/`
